## 7.11 트리거 설계 — "언제 앱을 여는가"의 설계

기능이 갖춰져도 "이 순간엔 무조건 무드핏"인 순간이 없으면 안 열린다. 트리거 3종 = 시간 / 사건 / 감정.

### 주력: 스크린샷 부하 (감정 트리거) — 구현 (`/shot`, `ShotFinder`)
- **"멋있다 싶으면, 무드핏으로 보내."** 유튜브·릴스·거리에서 본 걸 스샷 → 무드핏 → 근접 무드 그리드 → 실행(구매).
- 타겟 최고빈도 감정("저 사람 멋있다")이 곧 스크린샷 → 카메라롤 사장. 그 순간의 해소처가 없던 자리.
- **구현 범위(이번)**: 이미지 업로드 → "이 스샷이랑 비슷한 무드 골라봐" 그리드(유저가 근접 무드 선택 = 제0조 정합). 나의 공간에 진입점.
- **의존성(다음)**: 자동 무드 분류 = 비전 모델(근접 무드 분류만, 한 이미지 정밀 분석 아님). 진짜 OS 공유 수신 = PWA `share_target`/네이티브.
- 저작권: 유저 스샷은 개인 방의 사적 보관 + 무드 매칭 재료로만. 인스타 크롤링(공개 전시)과 법적 성격 다름.

### 보조: 콜드 모드 = "결제 완료 서비스" (v2.1 정련) — 다음
- 하루배송의 본질은 물류가 아니라 결제(결정 종료). 상황/날짜/예산 → 조합 2~3개 파일, "3분 안에 결정 끝".
- 자연 번역기(7.10, 이미 구현)와 겹침 → 상황×날짜 프레이밍만 얹으면 됨. 다음 스프린트.

### 첫 인상 감정 대응 — 구현 (`ResultsGrid`/`MoodCard`)
- 첫 검색 결과 **첫 카드에 해설 앵커 힌트("꾹 눌러봐")** 고정 → "통한다→답한다→내 눈으로도 이 산다" 3연타를 첫 화면에서. 롱프레스(길게 눌러 해줌) 발견성도 해결.
- 콜드스타트 분산은 2번째 카드부터 그대로.
