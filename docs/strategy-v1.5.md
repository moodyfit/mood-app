# 전략 v1.5 반영 노트 (무드핏 / MOODFIT)

v1.4 → v1.5 신규 섹션과 앱 구현 매핑. 핵심은 이 전부를 관통하는 **프로필 무드 벡터(affinity)** 도입.

## 프로필 무드 벡터 (affinity) — 7.6의 토대

`store.tsx`에 `affinity: Record<moodKey, number>` 추가 (localStorage 영속).
- 저장 시 `+2`(W_SAVE), 무드 상세 조회 시 `+1`(W_VIEW) 누적 — "프로필은 저장·클릭 시 누적"(7.6).
- 추구미 카드·무드 지도·방 레이아웃·개인화 정렬이 **전부 이 하나의 벡터**를 읽는다 → 저장이 균일(토글=1개)이던 문제 해소, 취향 비중이 실제로 생김.
- `taste.ts`의 `computeTaste`/`personalizeOrder`/`topShare`/`moodsByAffinity`가 affinity 기반으로 전환.
- (미구현) 최근 30일 recency 가중은 이벤트 타임스탬프 로그 필요 → v1.5+ 후보.

## 7.6 핀 매력 맵 — 개인화 정렬 정밀화

- **모두의 결과** = 검색어→사진 일치도(원순서, 중립). 인기순 아님.
- **너의 결과** = `일치도 × (1 + 프로필 가중치)` 재정렬 (`personalizeOrder`). 후보군 동일, 순서만 교체.
- **토글 노출 조건**: 카드 발급 이후 **AND** 프로필이 특정 축에 쏠렸을 때(`topShare ≥ 0.34`). 쏠림 없으면 노출 안 함 → `ResultsGrid`.

## 7.7 '내 방' — 개인 무드 공간 (`Room.tsx`, 기존 Moodboard 대체)

- **가중 레이아웃**: 저장 무드를 affinity 내림차순으로, 지배 무드는 크게(16:10 와이드), 나머지는 2열 → "너는 이런 비율의 사람"을 스크롤 없이.
- **미개척지**: 안 고른 무드를 흐릿한(grayscale/opacity) 실루엣 3열로, 누르면 그 무드로 이동 → 탐색 유도 + 취향 고착 방지(공간 버전 탐색 믹스).
- **문패**: 방 입구 "OO × OO의 방" — 카드가 일회성 발급물이 아니라 상시 거주.

## 7.8 검색 기억 (`SearchMemory.tsx`)

- 저장 시 검색어를 `SaveRecord.query`에 태깅.
- 같은 상황어 **재검색**(searchCount ≥ 2)이고 그 검색어로 저장한 룩이 있으면 결과 상단에 "지난번 'OO' 때 저장한 룩 N개" + 썸네일 → 해당 무드로 이동.
- "무신사는 검색을, 무드핏은 상황을 기억한다."

## 7.9 요구 설계 — 밥 칩과 오리지널드 아키타입

- **1층 추천 검색어 칩 (v1, 구현)**: 검색창 아래 일반 밥·상황 언어만("소개팅 깔끔하게","퇴근 남","꾸안꾸"…). **IP·실명 제외** — 연예인(퍼블리시티권)·웹툰/영화 캐릭터(타사 IP)는 공식 프리셋·버튼 금지.
- **2층 검색어 번역 (기존 resolveMoods)**: 유저가 뭘 치든 무드 축으로 번역, 화면엔 무드 사진만.
- **3층 오리지널드 아키타입 (v1.5+, 미구현)**: 무드 축을 우리 IP 인물로 의인화 → 온보딩/카드 연동. 밖에 나가는 건 전부 자체 IP. → 다음 스코프.
