# 전략 v2.5 반영 노트 (무드핏 / MOODFIT)

v2.1 → v2.5 델타(통념 파괴 II, '내 옷' 결, 체험 수치 재가이드)와 앱 구현 매핑.

## 1.5 통념 파괴 — '통째로 담기' v1 본진 (구현, `WholeLook`)

- 전 커머스 공통 통념: 구매 단위가 개별 상품(장바구니·상세). 꾸밈맹이 사고 싶은 건 낱개가 아니라 **"그 사진 그 무드"** → 산 옷이 옷장에서 죽는 구조적 원인.
- **오프라인 복원: "마네킹째 주세요."** 룩 전체를 **판매처별로 묶어** 한 번에 담기: "번개장터 → 셋업/니트/슬랙스, 크림 → 로퍼". 결정 1회, 고르는 고통 제거.
- 성립 조건(AI 스트릿샷 + photo_products + 판매처 횡단)이 다 갖춰진 유일 구조라 무신사가 못 함.

## 1.5.2 통념 파괴 II — 구매 후 3지점 (v1 부분 구현)

- **지점 1 "샀어?" (구현, `ProductRow`)**: 상품 카드에 [샀어/✓내 옷] 토글. "샀어" → 소유 결 적재 + (뒷단) 구매 매칭 데이터 = 겹4 방어(이 기능 없인 못 얻는 데이터).
- 지점 2 이어붙이기 알림(+2~3일), 지점 3 옷장 의존 확인(2주 후) → v1.5/v2.

## '내 옷' 결 — 나의 공간 3결 (구현, `Closet`)

- 동경(저장) / 발견(스크린샷) / **소유(내 옷)**. "샀어" 아이템이 모임.
- 아이템 탭 → **"이거 들어간 룩 보기"** = **상함형**(존재하는 무드 룩으로 이동). 제0조 경계 준수: ❌ 생성형 조합("이 바지 매치해봐" = 앱이 창작) 금지, ⭕ 상함형(있는 룩 필터)만.
- 저장 0이어도 소유 아이템 있으면 노출.

## 6장 체험 수치 재가이드 (v2.5) — 문서/이미지 소싱 지침

> **"데깽(착장)을 최대로, 단 데깽의 이유는 옷."**

- 인물의 홍보기 분위기는 허용하되, **몸 자체가 주인공인 사진**(과장 근육·벌크·과한 포즈)은 교체. 판정: "이 옷을 벗겨도 멋있는 사진인가?" → 그렇다면 반려.
- UGC 대비 진짜 차별점: 크리에이터는 몸·얼굴·옷 분리 불가, 우리는 생성이라 **멋의 성분(옷)만 통제** 가능.
- → 이미지 리생성 기준. 현 8장은 이미 이 기준 부합(옷 중심). 향후 리태깅/증량 시 적용. 앱 코드 변경 없음.
