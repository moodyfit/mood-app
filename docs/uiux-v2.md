# UI/UX 가이드라인 v2 적용 노트

원칙: **"최소한 몸, 다른 사장" — 화면은 최대한 대중적으로(관습 그대로), 알아채는 건 우리 것으로.**
유저가 새 UI 문법을 배우지 않게 하고, 새로움은 "무엇이 어떤 순서로 보이는가"에서만.

## 적용 완료 (이번)

- **하단 탭바 (§2, v1 금지 철회)**: `[홈][스캔][나의 공간]` 3탭 고정, 아이콘+라벨(`TabBar`). 상단바는 로고만으로 축소, 나의 공간 진입을 탭으로 이관.
- **컬러 토큰 (§3)**: bg `#FAFAF8` / bg-2 `#F2F1EE` / ink `#1A1A1A` / ink-2 `#8A8A86` / line `#E7E5DF`, 액센트=잉크 블랙. (tailwind + globals)
- **그리드 카드 (§4.2)**: 4:5 비율, 라운드 16. 완성가 라벨·해설 힌트 유지.
- **표준 제스처 (§2)**: 단일 탭=상세 / **더블탭=저장(인스타 문법)** / 롱프레스=해설. 하트 버튼 병존.
- **가격 tabular-nums (§3)**: 완성가·상품가·판매처가 `.tnum` 적용.
- **스캔 종료 = 탐색화 (§4.5)**: 결과 요약 화면 없이 바로 방향 그리드.
- **reduced-motion 존중 (§6)**.

## 의도적 편차 (전 지시와 충돌 → 사용자 선호 우선, 재조정 가능)

1. **폰트**: 문서는 "Pretendard 단일". 앞서 사용자가 **Wanted Sans**로 세련되게 바꾸라 지시하고 만족 → Wanted Sans 유지(단일 패밀리 취지 + tabular-nums는 반영). 영문/숫자 Space Grotesk 병용 유지.
2. **홈 히어로**: 문서 §4.1엔 히어로 미기재. 앞서 "홈은 완성형"이라 해 히어로("취향이 없는 게 아니다…") 유지.

## 아직 안 함 (다음)

- **콜드 모드 카드 (§4.1/§4.8)**: 홈 진입 카드 + 상황/날짜/예산 3스텝 시트 → 자연 번역기(7.10) 확장으로 붙일 것.
- **당겨서 새로고침 / 좌우 스와이프(하트 뷰)**: 표준 제스처 잔여.
- **스크린샷 부하 자동 분류(비전) + OS share_target**: 트리거 셸만 구현됨(/shot).
- **"더 보기" 페이지네이션**: 무드 8개라 현재 불필요, 사진 확충 후.
