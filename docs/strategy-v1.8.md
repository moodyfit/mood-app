## 제0조 — 모든 결정의 상위 (헌법 최상단)

> **"내 추구미만 모아두는 곳." / "취향은 유저의 것, 실행은 무드핏의 것."**

- 카테고리 정의 갱신: 옷 검색 앱이 아니라 **'내 추구미만 모아두는 곳'(장소화)**. 취향 번역은 이 장소가 작동하는 *방식*이지 정체성이 아니다.
- 포지셔닝 한 줄: **"설명 못 해도 눈에만 있으면, 사게 해준다."**
- 필터: 취향을 *정의/평가*하는 기능(진단·점수·교육) = 기각. 취향을 *실행 가능*하게(언어화·조합·연출·배송·정리) 만드는 기능 = 채택.
- 앱 반영: '나의 공간'(/space)이 곧 장소화의 구현체(프로필·지도·방·아카이브가 이 점을 향해 정렬). 홈은 완성형으로 유지.

## 7.10 wow 체계 — "무조건 써야 하는 이유"

### 본진: 자연 번역기 (v1, 구현) — `ProductSection`
- 꽂힌 룩(완성가)에서 **예산 4버튼(5만/10만/20만/상관없음)** → 같은 무드를 예산 안에서 재구성.
- 로직(`fitLookToBudget`): 최저가 기준, 싼 아이템부터 담아 예산 내 최대 커버. 초과분은 절출 제안("셋업 자켓 빼고 이 느낌의 75%"). 예산 밖 아이템은 흐리게 + "예산 밖" 태그.
- "같은 느낌, 다른 예산" — 취향(무드)은 그대로, 실행(예산)만 유저 것 = 제0조. 무신사가 구조적으로 못 하는 자리(판매처 횡단 + 무드 태깅 전제).
- 금지 지킴: "최저가/할인/가성비"가 아니라 **"내 예산으로 이 느낌"** — 열등한 복제가 아니라 다른 실행.
