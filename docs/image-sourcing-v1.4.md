# 이미지 소싱 전략 v1.4 — AI 스트릿샷 확정

> 무드 전달력이 가장 높은 이미지는 옷 정물이 아니라 **사람이 입고 멋있는 순간의 실사풍 샷**.

## 금지선 (저작권으로 즉사)

- 핀터레스트·인스타그램 크롤링 이미지의 서비스 내 전시.
- **연예인·셀럽 이미지 영구 불가** — 저작권 + 퍼블리시티권(부정경쟁방지법상 유명인 초상의 영리적 무단 사용 금지). 상품 링크가 붙는 상업 서비스에서 유명인 얼굴 사용은 소송 직결.
- 파파라치샷·공항패션·화보 크롤링 전부 동일하게 금지.

## AI 스트릿샷 생성 가이드 (파일럿 기준)

- **구도:** 스트릿 스냅 문법 — 전신~무릎 위, 자연광, 도시·일상 배경, 캔디드 포즈
- **톤:** 필름 그레인·자연스러운 색감 ("핀터레스트 감성" = 과도하게 꾸민 A컷 배제)
- **인물:** 20대 중후반 동아시아 남성 중심(타겟 투영) + 일부 다양화, 얼굴은 명확하되 실존 인물 비유사성 확인
- **의상:** 각 무드 축의 전형 코디 — 생성 후 창업자가 무드 축 태깅 + 유사 무드 실상품 3~5개 수동 매칭
- **파일럿:** 무드 축 6개 × 15~20장 = 약 100장 → 그리드 목업에 깔아 "무신사 대신 볼 만한 감성인가" 판정

## 구현 현황 (이 레포)

- **생성 모델:** Higgsfield **Soul 2.0** (`soul_2`) — UGC·패션 에디토리얼·리얼리스틱 전용. 3:4 portrait, 2k.
- **생성물:** 무드 축 8개 × 1장 = 8장 (파일럿 시드). `public/moods/<mood>.webp` (1536×2048 WebP).
- **프롬프트 공통 스펙:** "candid street style snapshot / mid-to-late 20s East Asian man / full body to above-knee / natural daylight / urban everyday background / candid pose / subtle film grain / natural muted color grading / **fictional person, not resembling any real celebrity**"
- **연결:** `src/lib/moods.ts` 의 각 무드 `imageUrl` → 그리드 카드·상세 히어로가 gradient 대신 실사진 렌더. gradient는 폴백으로 유지.
- **퍼블리시티권 준수:** 전 프롬프트에 실존 인물 비유사 명시. 연예인 검색어는 향후 `query_map` 레이어에서만 무드 축으로 번역(화면 노출 없음).
