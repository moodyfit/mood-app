## Problem

- **현재 동작(시작 시점)**: 홈 상단에 FEAT-032로 만든 "스타일" 축 탭(전체+6개)만 있음. TPO·무드로 둘러볼 방법은 `/promise`(약속 모드)로 페이지 이동해야만 가능.
- **기대 동작**: 홈에서 스타일뿐 아니라 TPO·무드 축으로도 그 자리에서 필터링(페이지 이동 없이), 더해서 축별 비율을 직접 지정하는 커스텀 필터.
- **영향 범위**: `src/app/page.tsx`(필터 UI 전체 교체), `src/components/FilterSheet.tsx`(신규), `src/lib/filters.ts`(신규), `src/lib/moods.ts`(OCCASIONS/VIBE_CHIPS 공용화), `src/lib/rank.ts`(`rankByVector` 추가), `src/components/HomeGallery.tsx`(`preRanked` prop 추가).

### 비즈니스 근거

취향(무드) 탐색 진입점을 홈 하나로 모아서, 상황·무드 기반 둘러보기가 즉시 가능하게 — 체류
시간·탐색 깊이 개선. 사진 볼륨이 적은 지금 단계에선 "약속 모드"(상황→3개 추천)의 압축 가치가
낮아져서, 그 역할도 사실상 이 필터로 흡수됨(아래 "약속 모드 숨김" 참고).

## 결정 (2026-11-26, 에린 — 진행하며 여러 번 수정)

### 1. 축 조합 방식 — 동시선택으로 전환(최초 결정 뒤집음)

- 최초 결정: "한 번에 축 1개만"(데이터 볼륨 부족 때문에 교집합 회피).
- 재검토 계기: 에린이 무신사 스냅 필터(성별/스타일/TPO 등 7개 축, 체크박스 다중선택,
  "N개의 스냅 보기" 실시간 카운트) 스크린샷 제시.
- 최종: **스타일/TPO/무드 세 탭 동시선택 가능**. 탭 안에서는 체크박스 다중선택(OR, 합집합),
  탭 사이는 AND(교집합). 데이터가 적어 교집합이 0장이 될 수 있는데, 무신사처럼 숨기지 않고
  **그대로 드러내서** 사용자가 보고 빼게 함.
- 단, **정확한 결과 수(숫자)는 노출하지 않음**(에린 피드백) — 0장일 때만 적용 버튼을 막고
  "조건에 맞는 사진이 없어요"로 표시, 그 외엔 그냥 "적용".

### 2. TPO/무드 필터링 방식 — AI 호출 불필요, 기존 매핑 재사용

- 최초 가정: TPO/무드 라벨을 `/api/search/translate`(AI 번역)로 보내 moodKeys를 받아야
  한다고 봤음(로딩 상태 UI까지 필요하다고 적었었음).
- 재확인 결과: `src/lib/moods.ts`의 `QUERY_MAP`에 `OCCASIONS`(첫 소개팅 등)·`VIBE_CHIPS`
  (꾸안꾸 등) 라벨이 **이미 전부 정적으로 축 매핑**돼 있음(`resolveMoods()`로 동기 조회,
  네트워크 호출 없음). AI 번역은 필요 없어짐 — 로딩 UI도 불필요.
- 필터 판정: 체크된 라벨들의 `resolveMoods()` 결과 축을 합쳐서(탭 내 OR), 사진의
  `dominantMood`가 그 안에 있으면 통과.

### 3. UI 구조 — 무신사처럼 "하나의 시트 + 탭 전환"

- 중간에 "축마다 따로 열리고 닫히는 패널"로 갔다가, 에린 피드백으로 **"시트 하나, 안에서
  탭(스타일/TPO/무드)을 자유롭게 넘나들며 여러 축을 동시에 고른 뒤 적용 버튼 하나로 반영"**
  구조로 최종 정리.
- 진입점: 메인 화면에 맨 앞 아이콘 전용 버튼(☰) + "스타일 ⌄" / "TPO ⌄" / "무드 ⌄" 모서리둥근
  사각형 칩 3개 — 뭘 눌러도 같은 시트가 열리고 그 축 탭이 활성화됨. 칩 크기는 작게, 화살표는
  SVG 쉐브론(유니코드 문자 대신 — 세로 쏠림 방지, flex로 중앙 정렬).
- 리셋: 탭별 "초기화"(그 탭만 비움) + 시트 하단 "전체 초기화"(스타일·TPO·무드·커스텀 전부
  비우고 바로 적용/닫힘 — 다른 탭에 남은 선택을 잊은 채 테스트하다 "안 바뀐다"고 느끼는 문제
  방지용으로 추가).

### 4. 커스텀 비율 필터 — 범위에 새로 추가된 기능

- 회의록의 "커스텀 필터 추가"가 원래는 FEAT-041과 별개로 언급됐었는데, 구현 중 "슬라이더로
  미니멀 80%, 캐주얼 50% 이런 식으로 비율 지정" 아이디어로 실제 요청받아 이번 범위에 포함됨.
- 메커니즘: 체크박스는 **필터**(걸러내기)지만 이건 **랭킹**(순서 매기기) — `rankByVector()`
  (`src/lib/rank.ts`)가 슬라이더 비율 벡터와 사진 `mood_vector`를 내적(dot product)해서
  점수 매기고 정렬만 함. `rankPersonalized`의 기존 raw 점수 수식을 그대로 재사용.
  **0장이 되는 일이 없음**(필터가 아니라서) — 그래서 "한 번에 축 1개"보다 데이터가 적은
  지금 상황에 오히려 더 잘 맞음.
- 위치: 스타일 탭 체크박스 목록 **아래** 접이식 아코디언("커스텀 필터", 평소 접힘). 체크박스
  선택과 슬라이더는 서로 대체(값 생기면 반대쪽 비움).
- 자체 버그 발견·수정 2건(둘 다 Playwright로 재현·검증 완료):
  1. 시트를 안 닫고 TPO·무드를 먼저 고른 뒤 스타일 탭 슬라이더로 적용하면, 아직 "적용" 전
     상태(시트 안 draft)였던 TPO·무드가 반영 안 되고 날아감 — `onApplyCustom`이 draft 전체를
     받도록 고침.
  2. 커스텀이 켜져도 TPO·무드는 계속 AND로 걸려야 하는데, `genderedPhotos` 전체를 그대로
     랭킹해버려서 TPO·무드 칩에 숫자가 남아있어도 실제로는 적용 안 되고 있었음 — TPO·무드로
     먼저 거르고 그 안에서만 커스텀 비율로 순위를 매기도록 고침.
- 전용 초기화 버튼 있음(슬라이더만 0으로).

### 5. 약속 모드(`/promise`) 홈 진입 카드 숨김 — 이 작업 중 같이 결정됨

- 배경: 회의록은 "필터 칩 생기면 약속 카드 생략 **가능**"이라고만 적었지, 확정은 아니었음.
- 에린 판단: (a) 필터 칩이 상황별 추천 역할을 사실상 대체, (b) 원래 있던 예산(가격) 입력이
  가격 데이터 신뢰도 문제로 이미 빠져서 "약속"만의 차별점이 옅어짐, (c) 팀 의견도 "3개
  추천보다 홈처럼 계속 둘러보는 게 낫다"는 쪽.
- 결정: **완전 삭제가 아니라 홈의 진입 카드만 제거**. `/promise` 라우트·`PromiseMode.tsx`는
  그대로 둬서, 나중에 홈에 Link만 다시 붙이면 복원 가능(FEAT-030의 "숨기기만" 패턴과 동일).

### 6. 검색창 문구 — "검색창 통합" 티켓의 경량 버전

- 조사 결과: `/results`가 이미 상품명 매칭 실패 시 `resolveMoods`(QUERY_MAP) → 필요하면
  AI 번역으로 자동 폴백하고 있어서, **백엔드 로직은 이미 상품명+TPO+무드를 전부 처리함**.
  "입구가 둘"이라던 회의록 문제는 로직이 아니라 `/search` placeholder가 "제품명 전용"으로
  못박혀 있던 **문구/기대치 문제**였음.
- 약속 모드 진입 카드도 숨긴 지금, `/search`가 사실상 유일한 검색 입구라 문구만 교체:
  "제품명으로 검색해봐 — 예) 와이드 슬랙스" → "슬랙스든 비 오는 날 느낌이든, 뭐든 검색해봐".
  **로직·라우팅 변경 없음**(`git show`로 diff 확인, placeholder+주석 한 줄씩만).
- "비 오는 날"처럼 QUERY_MAP에 없는 자유 문구도 `/api/search/translate`가 Claude로 직접
  6축에 매핑해주므로(이미 있는 기능) 예시로 넣어도 실제로 작동함.
- `/promise`·`/search`의 더 큰 구조 변경(예: `/promise` 완전 삭제, 홈 인라인 검색 복원 등)은
  이번 범위 밖 — 필요해지면 별도 티켓.

## Verification

Playwright로 전부 실측 확인(각 커밋 메시지에 재현 스크립트 요지 포함):

1. 스타일=미니멀만 → 10장. 스타일=미니멀 + TPO=첫 소개팅(겹치는 축 있음) → 그대로 10장.
   스타일=스트릿 + TPO=주말 카페(안 겹침) → 0장, 버튼 비활성화.
2. 시트 안 닫고 TPO→무드→스타일 탭 순서로 이동하며 각각 선택 후 적용 → 전부 한 번에 반영.
3. 커스텀: 슬라이더 드래그만으론 사진 안 바뀜(적용 눌러야 반영). 적용 후 TPO 필터(street
