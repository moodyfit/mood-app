# FEAT-025: 검색 결과 헤더 문구 정리

## Problem

사용자 테스트(search 결과 화면 스크린샷 기반): 헤더 "'q' — 대충 쳐도 돼"의 "대충 쳐도 돼"가
제품 검색에는 안 어울림(자연어 검색 전용 톤).

## 경과(카드 캡션 쪽은 결국 원복)

처음엔 "첫 카드(히어로/hint)만 캡션이 보이고 나머지는 롱프레스해야만 보여서 비일관적"이라는
피드백도 같이 반영하려고 `PhotoCard.tsx`를 "모든 카드에 제목 상시 노출"로 바꿨다가, 다시
"아예 캡션 자체를 없애는" 쪽으로 바꿨다 — 하지만 소피 코드리뷰에서 "원래 보고된 변경 전 상태는
main처럼 히어로/첫 카드만 캡션, 나머지는 사진만"이었다는 걸 확인해 주면서, 캡션 쪽은 **main
동작(hero/hint 카드만 캡션) 그대로 원복**했다. 이 티켓에서 실제로 남은 변경은 헤더 문구뿐이다.

## Scope

- `PhotoGrid.tsx`, `ResultsGrid.tsx`: 헤더에서 "— 대충 쳐도 돼" 제거, 검색어만 표시.
- `PhotoCard.tsx`, `HomeGallery.tsx`: 캡션/`hint` 로직 변경 없음(main과 동일).

## Verification

- 로컬에서 `/results?q=와이드+슬랙스` 확인 — 헤더가 `'와이드 슬랙스'`로 단순화, 카드 캡션은
  main과 동일(히어로/첫 카드만 상시 노출, 나머지는 롱프레스).
- `tsc --noEmit`, `npm run build` 통과. PR #43(재오픈).
