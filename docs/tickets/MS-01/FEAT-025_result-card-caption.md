# FEAT-025: 검색 결과 헤더 문구 정리 + 카드 캡션 완전 제거

## Problem

사용자 테스트(search 결과 화면 스크린샷 기반):
- 헤더 "'q' — 대충 쳐도 돼"의 "대충 쳐도 돼"가 제품 검색에는 안 어울림(자연어 검색 전용 톤).
- 첫 카드(히어로/hint)만 캡션(제목+부가설명)이 보이고 나머지는 롱프레스해야만 보여서
  비일관적이라는 피드백으로 시작 → 처음엔 "모든 카드에 제목 상시 노출"로 구현했으나, 소피
  코드리뷰(Q-1·P2-1)에서 홈 피드까지 전부 캡션이 붙는 게 지저분해 보인다는 지적, 사용자도
  실제 화면을 보고 "전체 노출은 지저분하다" 재확인 → 팀 의견 수렴 후 **카드 상시 캡션을
  아예 없애는 쪽으로 최종 결정**(2026-11-11).

## Scope

- `PhotoCard.tsx`: 상시 노출 캡션 밴드(제목 + 그라데이션) 완전 삭제 — 카드는 어떤 size든
  사진만 보여준다. 롱프레스 시 전문 오버레이(제목+부가설명)는 그대로 유지.
- `PhotoGrid.tsx`, `ResultsGrid.tsx`: 헤더에서 "— 대충 쳐도 돼" 제거, 검색어만 표시(유지).
- `HomeGallery.tsx`: `hint` prop 제거는 유지(캡션 자체가 없으니 hero/hint 구분이 필요 없어짐).

## Verification

- 로컬에서 `/`, `/results?q=와이드+슬랙스` 확인 — 어떤 카드에도 제목 밴드가 안 보이고,
  롱프레스하면 전문 오버레이는 그대로 뜸.
- 헤더가 `'와이드 슬랙스'`로 단순화된 상태는 유지.
- `tsc --noEmit`, `npm run build` 통과. PR #43.
