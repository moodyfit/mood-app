# FEAT-028: 제품 검색 — 표기 차이 변형 매칭

## Problem

#41(FEAT-023) 코드리뷰(소피) P2-1. `fetchProductPhotoUrls`(`src/lib/photos.ts`)의 글자 순서
매칭은 띄어쓰기 변형은 잡지만 표기 차이는 못 잡는다. `products.name`에 `자켓` 26행과 `재킷` 4행,
`후디` 12행과 `후드` 8행이 섞여 있어 `자켓`으로 검색하면 `재킷` 표기 상품을 놓친다. 사용자 입력도
두 표기를 섞어 쓰기 때문에 검색어 쪽에서도 같은 문제가 생긴다.

## Scope

- 실데이터에서 확인된 표기 쌍(`자켓/재킷`, `후디/후드`)만 — 검색어에 이 중 하나가 있으면 변형
  패턴을 OR로 묶어 함께 조회.
- DB 표기 통일은 사용자 입력 쪽 문제가 남아 범위 밖. 일반 동의어 사전은 과설계 — 쌍 목록은
  실데이터 기준으로만 유지.

## Verification 기준

- `데님 자켓`으로 검색하면 `재킷` 표기 상품이 들어간 코디도 나와야 한다.
