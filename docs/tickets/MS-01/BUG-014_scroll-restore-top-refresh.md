# BUG-014: 맨 위로 스크롤 후 새로고침하면 아래로 복원됨

## Problem

2026-11-16 회의록: "새로고침 시 스크롤 위치가 달라짐 — 메인 페이지에서 스크롤 위로 올린 후
맨 위에서 새로고침하면 아래 스크롤로 내려가는데".

## 원인

`useScrollRestore.ts`의 onScroll 저장 로직이 `scrollY<=0`인 이벤트를 저장하지 않는다
(BUG-011 — 사진 클릭→상세 이동 시 Next.js가 일시적으로 스크롤을 0으로 리셋하는 걸 실제 위치로
착각해 저장해버리는 레이스를 막기 위함). 그런데 이 가드가 "사용자가 실제로 맨 위까지 스크롤한
경우"도 똑같이 걸러낸다.

재현: 스크롤을 내림(예: 2000px, sessionStorage에 저장됨) → 다시 맨 위로 올림(0, 가드 때문에
저장 안 됨 — sessionStorage엔 여전히 2000이 남음) → 새로고침 → 마운트 시 sessionStorage의
낡은 값(2000)으로 복원.

## Fix

`pagehide` 이벤트(실제 문서 언로드 — 새로고침·탭 닫기에서만 발생, Next.js App Router의
클라이언트 사이드 네비게이션(`router.push`)에서는 발생하지 않음)에서 현재 `scrollY`를
무조건(0이어도) 저장하도록 effect를 추가. 기존 onScroll의 y<=0 스킵 가드는 그대로 둬서
BUG-011이 막았던 레이스는 재발하지 않는다 — pagehide는 그 레이스가 일어나는 SPA 네비게이션
경로와 겹치지 않는다.

## Verification

- 로컬 `/`에서 스크롤 내림 → 맨 위로 올림 → 새로고침 → 맨 위 유지되는지 확인.
- 기존 동작(사진 클릭→상세→뒤로가기 시 스크롤 복원, BUG-004/008/011)에 회귀 없는지 확인.
- `tsc --noEmit`, `npm run build` 통과.
