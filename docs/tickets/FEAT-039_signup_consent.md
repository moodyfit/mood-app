## Problem

- **현재 동작**
  - 이메일 · 비밀번호만 받고 가입된다. 약관 · 처리방침 동의와 만 14세 이상 확인이 없고, 동의 기록도 없다
  - 카카오 로그인(FEAT-038)은 처음 오는 계정을 동의 없이 자동 가입시킨다
  - Confirm email이 꺼져 있어 이메일 가입은 확인 메일 없이 가입 즉시 Confirmed가 된다. 남의 이메일로 먼저 가입하면 그 사람의 카카오 로그인이 그 계정에 자동 연결된다(계정 선점). 관리자 게이트(`ADMIN_EMAILS` 이메일 비교)도 같은 이유로 이메일 소유를 보장하지 못한다
- **기대 동작**
  - 이메일 · 카카오 가입 모두 필수 동의를 마쳐야 서비스를 쓴다. 동의 시각 · 약관 버전이 계정에 남는다
  - 이메일 가입은 확인 메일의 링크를 눌러야 로그인된다
- **영향 범위**: `/login` 회원가입 모드, 카카오 첫 로그인 직후, Supabase Auth 설정 · 메일 템플릿

## Scope

### 포함

1. **회원가입 동의 체크** — `/login` 회원가입 모드에 전체 동의 + 필수 3개(만 14세 이상 · 이용약관 · 개인정보 수집 · 이용), 약관 · 처리방침 링크. 필수를 모두 체크해야 가입 버튼이 켜진다
2. **동의 기록** — `signUp`의 `options.data`로 `user_metadata`에 `consent: { at, terms_version, age14 }` 저장. 테이블 추가 없음
3. **카카오 가입 동의** — 로그인 후 `user_metadata.consent`가 없으면 동의 화면을 띄운다. 동의하면 `updateUser({ data })`로 기록, 거절하면 로그아웃
4. **비밀번호 확인 입력** — 회원가입 모드에 확인 칸, 두 칸이 다르면 "두 비밀번호가 달라." 표시. 재설정 화면(FEAT-034)과 같은 방식
5. **Confirm email 켜기** (서영 · 대시보드) — 가입 후 "확인 메일을 보냈어" 안내(스팸함 확인 포함), 확인 링크는 `/space`로
6. **확인 메일 템플릿** (서영 · 대시보드) — Confirm signup 한국어 합쇼체, 제목 "[무드핏] 이메일 주소 확인 안내"

### 제외

- 마케팅 수신 동의 — 발송 계획 없음(FEAT-033)
- 법정대리인 동의 — 14세 미만은 가입을 받지 않음
- 관리자 게이트를 사용자 ID 기준으로 변경 — Confirm email로 이메일 소유가 보장돼 지금은 불필요. 관리자를 늘릴 때 다룬다
- 이미 가입한 계정의 이메일 재확인 — 기존 계정은 그대로 둔다

## 결정

- 개인정보 동의는 법정 고지(수집 항목 · 목적 · 보유 기간 · 거부권)를 펼치기로 그 자리에 보여 준다. 처리방침 링크만으로는 고지가 부족하다. 약관도 같은 펼치기로 조항 제목 요약을 보여 주고 전문 페이지로 연결한다(두 "보기"의 동작을 맞춘다)
- 동의 기록은 `user_metadata`에 둔다. 별도 테이블은 DDL이 필요하고, 계정 하나에 동의 한 번이면 충분하다
- 카카오는 버튼 한 번에 가입 · 로그인이 같이 일어나 미리 동의를 받을 수 없다. 로그인 후 기록이 없을 때 받는다
- 카카오 동의를 거절하면 로그아웃만 한다. 계정은 남지만 동의 기록이 없어 다시 로그인하면 동의 화면이 뜬다. 계정 삭제는 서비스 키 API가 필요해 FEAT-036(회원 탈퇴)과 함께 다룬다
- 개인정보 수집 · 이용도 필수 동의 체크로 받는다. 계약 이행에 필요한 수집은 고지만으로 가능하다는 해석도 있으나, 체크가 해석과 무관하게 안전하다

## Implementation Notes

### 확인 링크 복귀 위치

확인 링크는 누르는 순간 로그인까지 된다. 처음에는 `/login`으로 돌아오게 해 "이미 로그인됨"이 떴다. 가입 때 동의를 이미 기록하므로 `/space`로 바로 보낸다.

### 확인 메일 스팸 분류

2026-11-22 별칭 주소(`seoy1108+test1~4@gmail.com`)로 보낸 확인 메일이 네 번 연속 Gmail 스팸함으로 갔다. 같은 Gmail SMTP로 보낸 재설정 메일은 받은편지함으로 왔었다. 같은 날 같은 발송 주소로 테스트 메일을 여러 통 보냈고, 별칭 주소 · 새 템플릿 · 발송 빈도 중 원인은 확인하지 않았다. 가입 안내에 스팸함 확인을 넣었고, 자체 도메인 · 메일 발송 서비스(SPF · DKIM)는 별도 논의다.

### 기존 계정 · 카카오 연결 끊기

동의 기능 이전에 가입한 계정은 동의 기록이 없어 다음 로그인 때 약관 동의 화면이 한 번 뜬다. 기존 계정에 동의 기록을 일괄로 넣지 않는다(실제로 동의받지 않았다). 카카오 연결 끊기는 무드핏 탈퇴와 별개로 보아 계정 · 동의 기록을 그대로 둔다.
