## Problem

- **현재 동작**
  - 이메일 · 비밀번호만 받고 가입된다. 약관 · 처리방침 동의와 만 14세 이상 확인이 없고, 동의 기록도 없다
  - 카카오 로그인(FEAT-038)은 처음 오는 계정을 동의 없이 자동 가입시킨다
  - Confirm email이 꺼져 있어 이메일 가입은 확인 메일 없이 가입 즉시 Confirmed가 된다. 남의 이메일로 먼저 가입하면 그 사람의 카카오 로그인이 그 계정에 자동 연결된다(계정 선점). 관리자 게이트(`ADMIN_EMAILS` 이메일 비교)도 같은 이유로 이메일 소유를 보장하지 못한다
- **기대 동작**
  - 이메일 · 카카오 가입 모두 필수 동의를 마쳐야 서비스를 쓴다. 동의 시각 · 약관 버전이 계정에 남는다
  - 이메일 가입은 확인 메일의 링크를 눌러야 로그인된다
- **영향 범위**: `/login` 회원가입 모드, 카카오 첫 로그인 직후, Supabase Auth 설정 · 메일 템플릿

## Scope

### 포함

1. **회원가입 동의 체크** — `/login` 회원가입 모드에 전체 동의 + 필수 3개(만 14세 이상 · 이용약관 · 개인정보 수집 · 이용), 약관 · 처리방침 링크. 필수를 모두 체크해야 가입 버튼이 켜진다
2. **동의 기록** — `signUp`의 `options.data`로 `user_metadata`에 `consent: { at, terms_version, age14 }` 저장. 테이블 추가 없음
3. **카카오 가입 동의** — 로그인 후 `user_metadata.consent`가 없으면 동의 화면을 띄운다. 동의하면 `updateUser({ data })`로 기록, 거절하면 로그아웃
4. **Confirm email 켜기** (서영 · 대시보드) — 가입 후 "확인 메일을 보냈어" 안내, 확인 링크는 `/login`으로
5. **확인 메일 템플릿** (서영 · 대시보드) — Confirm signup 한국어 합쇼체, 제목 "[무드핏] 이메일 주소 확인 안내"

### 제외

- 마케팅 수신 동의 — 발송 계획 없음(FEAT-033)
- 법정대리인 동의 — 14세 미만은 가입을 받지 않음
- 관리자 게이트를 사용자 ID 기준으로 변경 — Confirm email로 이메일 소유가 보장돼 지금은 불필요. 관리자를 늘릴 때 다룬다
- 이미 가입한 계정의 이메일 재확인 — 기존 계정은 그대로 둔다

## 결정

- 동의 기록은 `user_metadata`에 둔다. 별도 테이블은 DDL이 필요하고, 계정 하나에 동의 한 번이면 충분하다
- 카카오는 버튼 한 번에 가입 · 로그인이 같이 일어나 미리 동의를 받을 수 없다. 로그인 후 기록이 없을 때 받는다
- (대기) 카카오 동의 거절 시 계정 처리 — 로그아웃만 할지, 생성된 계정을 지울지(FEAT-036 회원 탈퇴와 엮임)
- (대기) 개인정보 "동의" 체크 대신 "확인" 고지로 둘지 — 계약 이행에 필요한 수집은 동의 없이 고지만으로 가능하다는 2023 개정법 해석. 서영 확인
