# FEAT-027: 내 옷장 미리보기 — 상품 크롭 1:1 가로 줄

나의 공간의 내 옷장을 상품 크롭 이미지의 1:1 카드로 가로로 넘겨 보여 준다. 카드를 누르면 그 상품이 든 코디로 간다.

## Problem

- **현재 동작**: 내 옷장 미리보기가 상품을 담은 코디의 전신 사진을 정사각 4열로 잘라 보여 준다. 한 코디에서 여러 벌을 담으면 같은 사진이 반복되고, 어떤 옷인지는 아래 글자로만 구분된다. 4벌까지만 보이고 나머지는 [더보기]로 넘어간다
- **기대 동작**: 카드마다 그 상품의 크롭 이미지가 보이고, 위 '내 취향 코디'와 같은 가로 줄 형식으로 담은 옷 전부를 넘겨 본다
- **영향 범위**: `/space` 내 옷장 섹션

---

## Context

```
관련 파일:
- src/app/space/page.tsx          나의 공간 — 내 옷장 미리보기
- src/components/ShelfCard.tsx    섹션 헤더 · 가로 줄 · 3:4 카드 (FEAT-026)
- src/lib/hooks/usePhotos.ts      usePhotoProducts — 코디 사진별 상품(크롭 imageUrl 포함)
```

- 상품 크롭 이미지는 FEAT-017에서 코디 사진의 아이템 부위를 잘라 만든 것이다. 336장 중 335장이 1:1이다
- 담은 옷(`OwnedItem`)에는 이미지가 없고 `photo`(담은 코디)와 상품 `id`만 있다. 크롭은 `usePhotoProducts()`에서 `photo` → 상품 목록 → `id`로 찾는다

---

## Scope

### 포함

1. `src/components/ShelfCard.tsx` — 카드 비율 옵션(3:4 기본, 1:1)
2. `src/app/space/page.tsx` — 내 옷장을 4열 격자에서 가로 줄 · 1:1 카드로, 담은 옷 전부(최근 담은 순), [더보기] 대신 헤더 "N벌 ›"(`/closet`)
3. 썸네일: 크롭 → 코디 사진 → 무드 이미지 순. 상품을 불러오는 동안은 빈 칸
4. 카드 링크: 코디 상세(`/photo?slug=`). 사진 없이 담은 옷은 옷 상세(`/closet/item`)

### 제외

- `/closet` 전체 목록의 상품 줄 크롭·가격·빼기 버튼 → 별도 티켓
- 옷 상세(`/closet/item`) 화면

---

## 결정

- 카드는 1:1이다. 크롭 이미지가 거의 모두 정사각이라 3:4로 두면 위아래가 잘린다
- 카드를 누르면 코디 상세로 간다. 담은 옷이 든 코디와 같이 담을 다른 아이템을 다시 보는 동선이다
- 상품을 불러오기 전에는 코디 사진을 보여 주지 않는다. 코디 사진이 보였다가 크롭으로 바뀌는 깜빡임을 막는다
