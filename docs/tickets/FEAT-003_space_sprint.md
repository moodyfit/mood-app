## Problem

- **현재 동작**: 탭바 4탭, 나의 공간 구조가 산만, '저장'/'좋아요'/'담기' 혼용
- **기대 동작**: 탭바 2탭(홈/나의 공간), 나의 공간 핵심 집중(카드+공유+내옷), 용어 '담기' 통일
- **영향 범위**: TabBar, space/page, TasteProfile, TasteCardModal, Closet, store.tsx 토스트/안내 문구

### 비즈니스 근거

> 팀 회의(8/23) 확정. 마케팅 단계 진입 전 핵심 기능에 집중. 취향 카드 공유 = 바이럴 요소. 용어 '담기'로 커머스 UX 문법 통일.

## Scope

### 포함 (구현 완료)

1. **탭바**: 4탭 → 2탭 (홈/나의 공간), 스캔·영상 탭 제거
2. **헤더 검색 분리**: TopBar에 돋보기 아이콘 추가, `/search` 페이지 신규 생성 (검색 입력 + 상황·밈 칩 + 무드 6축 그리드 + 스크린샷 올리기)
3. **나의 공간 리디자인**: 8섹션 → 3블록 구조
  - 블록 1: 취향 카드 + 공유 아이콘 (Web Share API + 클립보드 폴백), 빈 상태 CTA "둘러보기 →"
  - 블록 2: 내 옷 썸네일 프리뷰 4개 + "N벌 ›" 링크 + "더보기" 버튼
  - 블록 3: 로그인/계정
4. **용어 통일**:
  - '저장' → '담기' (10곳): 토스트, aria-label, 안내 문구 전체
  - '샀어' → '담기'/'담을래?' (2곳): ProductRow 인라인 복귀 감지
  - 구매 맥락 '담기' → '사기'/'구매' (3곳): WholeLook CTA + 판매처 버튼
  - 용어 규칙: '담기' = 앱 내 저장, '사기'/'구매' = 외부 판매처 이동

### 제외

- /scan, /watch 라우트 삭제 (탭에서만 제거)
- 공유 시 이미지 생성/캡처 (후속)
- 가격 보여주기 (후순위)
- 코드 내부 변수명/주석 변경
