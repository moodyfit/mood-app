# FEAT-020: 무드 상세 다른 코디 고르기

## Problem

- **현재 동작**: 무드 상세는 대표 사진 1장의 코디만 보여준다. 무드마다 사진이 17~22장(성별 필터 시 7~12장) 있지만 무드 상세에서 볼 방법이 없다
- **기대 동작**: 큰 사진 아래 "이 무드의 다른 코디" 썸네일 줄에서 다른 코디를 골라 같은 화면에서 사진·해설·상품·완성가를 본다
- **영향 범위**: 무드 상세(`MoodDetail`·`MoodHero`·`ProductSection`), 신규 `LookStrip`, `usePhotos` 훅, `photos.ts`, 공용 `BackButton`(전 화면), 하트 토스트(`store.tsx`), 사진 상세(`PhotoProductView`), 공용 토스트(`Toast`), 나의 공간 취향 카드(`TasteProfile`·`TasteCardModal`)

### 왜 썸네일 줄인가

스와이프와 썸네일 줄 목업을 비교했다(`FEAT-020_swipe-mockup.png`, `FEAT-020_thumbstrip-mockup.png`). 스와이프는 넘길 수 있다는 걸 알기 어렵고, 사진 영역이 iOS 화면 왼쪽 끝 뒤로가기 제스처와 겹친다. 썸네일 줄은 몇 장인지·어떤 코디인지 미리 보이고, 원하는 코디로 바로 간다.

## 결정

- 순서: 대표 사진 첫 칸 → 나머지는 대표 사진과 비슷한 순(`rankSimilarPhotos`)
- 성별 `전체`: 남녀 사진 모두
- 다른 화면에 갔다 오면 대표 사진으로 시작한다(저장 안 함). 무드 카드·약속 모드 금액과 늘 일치
- 사진 1장 이하·대표 사진 없음: 줄 숨김. 선택 사진 상품 0개: 상품 섹션·담기·칩 숨김. 사진별 상품은 처음에 한 번에 받아 두어 코디를 바꿀 때 조회·깜빡임이 없다
- 성별 필터를 바꿔 선택 사진이 목록에서 빠지면 대표 사진으로
- 목업대로 해설 바로 아래 상품 목록. "이게 뜬 이유" 박스는 뺀다 — 큰 사진·썸네일 줄과 같은 사진을 한 번 더 보여주는 자리였다
- `대표` 라벨은 첫 칸에만. 같은 무드 대표 사진(`is_flagship`)이 `전체` 필터에서 4장이라 전부 붙이면 "대표가 여러 개"로 읽힌다
- 무드 이름: 셰브론과 한 줄에 `mood.name`, 아래 `mood.description`(목업 `FEAT-020_mood-label-mockup.png` A안). 썸네일 사진은 모두 이 무드가 주축이라 코디를 바꿔도 같다
- 스켈레톤: 큰 사진(3:4)·썸네일 7칸·해설 4줄·상품 3장(141px). 대표 사진을 못 불러오면 내장 이미지·`mood.caption`(목업 `FEAT-020_skeleton-mockup.png`)
- 하트: 무드 단위 저장이라 모든 코디에 하트가 켜져 보였다 → 지금 보는 사진 단위로. 취향 점수가 사진의 섞인 무드대로 오르고, 코디마다 저장 수가 센다
- 해설을 썸네일 줄 위로 옮기는 안(첫 화면에 해설까지)은 목업 비교 후 지금 배치 유지(`FEAT-020_fold-mockup.png`)
- 사진 상세는 큰 제목 대신 사진 위 무드 칩. 홈 카드에서 본 해설이 상세 첫 문구로 이어져야 해서 무드 이름은 보조로 둔다. 칩을 누르면 그 무드 상세(다른 코디)로
- 사진 상세에도 하트. 무드 상세·홈 피드와 같은 사진 저장이라 세 화면의 하트 상태가 같다. 해제할 때는 토스트 없음(아이콘이 바로 바뀌고 다시 누르면 된다, 옷장 담기와 같은 규칙)
- 하트 토스트 링크는 `/results?you=1`. 하트로 저장한 사진을 보는 화면이 없어 `/space` 는 막다른 길이었다. 결과 페이지는 저장 목록이 아니라 취향 점수로 정렬한 추천이라 "내 취향 코디 보기"로 쓰고, 같은 목적지인 취향 카드 버튼·모달 문구도 맞춘다
- 결과 페이지에서는 하트 토스트를 띄우지 않는다. 하트를 누르면 정렬이 바로 바뀌어(홈과 같음) 그게 피드백이다. 결과 페이지에 저장 수·기준 사진을 보여주는 안(문구·배지·막대·썸네일 목업 `FEAT-020_results-basis-mockup.png`)은 이번엔 넣지 않는다

- [x] 썸네일 개수가 성별 필터를 따른다(남 10 / 여 7~12 / 전체 17~22)
- [x] 썸네일을 탭하면 사진·완성가·해설·상품이 그 사진 것으로 바뀌고 `n / N` 이 바뀐다
- [x] 다른 코디에서 `코디 통째로 담기` → 담긴 옷의 출처가 그 사진이다
- [x] 다른 화면에 갔다 오면 대표 사진으로 시작한다
- [ ] 상품 없는 사진은 상품 섹션·담기·칩 없이 사진·해설만 보인다 — 지금 상품 없는 사진이 없어 코드 경로만 확인
- [x] 해설 바로 아래 상품 목록이 오고, "이게 뜬 이유" 박스가 없다
- [x] 불러오는 동안 사진·썸네일·해설·상품 자리에 스켈레톤이 있고, 로딩 후 자리가 밀리지 않는다
- [x] 썸네일을 바꿀 때 상품·완성가가 사라졌다 나타나지 않는다
- [x] 하트가 지금 보는 코디에만 켜지고, 토스트에 `내 취향 코디 보기` 링크가 있다
- [x] 사진 상세에 무드 칩과 하트가 있고, 칩을 누르면 그 무드 상세로 간다
- [x] 결과 페이지에서 하트를 눌러도 토스트가 뜨지 않고, 다른 화면에서는 링크와 함께 뜬다
- [x] `/results?you=1` 로 가는 문구가 세 곳 모두 "내 취향 코디 보기"다

## 후속 작업

1. 하트와 담기 — 회의 안건. 하트(사진 저장)와 옷장 담기가 둘 다 "담았어"인데 하트로 저장한 사진은 볼 곳이 없다(FEAT-003 에서 '내 방' 삭제). 홈 피드 하트를 코디 담기로 통일할지, 저장 목록(FEAT-021)을 둘지 정한다. 무드 상세 하트는 `코디 통째로 담기`와 겹친다
2. 옷장에서 빼도 취향 점수가 안 빠지는 비대칭(`toggleOwned`), 옷장 담기가 취향 카드 단계 셈에 안 들어감
3. 내 옷장 화면도 셰브론·제목 한 줄로 맞추기
4. 취향 카드 — 무드 비율 막대·근거 사진·확정 진행도, 실제 통계가 아닌 "전체의 7%" 삭제(목업 `FEAT-021_taste-card-mockup.png`)
5. 사진 상세 UI — 무신사 스냅 구성 참고: 사진 아래 상품 가로 줄(#34 크롭 썸네일, 첫 화면에 사진·상품·해설), `AI로 생성` 표시, 상황·계절 태그(`situations`·`seasons`), 행동 줄(하트·공유)
6. 홈 피드 — PC 호버·모바일 스크롤 중앙 카드에 해설 띠, 성별 필터 디자인
7. 결과 페이지 — 정렬 근거(하트 누른 코디) 표시, 취향 점수가 많이 쌓이면 하트 하나로 순서가 거의 안 바뀌는 문제(개인화 강도 `rank.ts`)
