## Problem

- **현재 동작**: `/terms` · `/privacy`(FEAT-033)로 가는 링크가 없다. 주소를 직접 입력해야 열린다. `[시행일]` · `[전화번호]`가 자리 표시로 남아 있다
- **기대 동작**: 나의 공간 하단에서 두 문서로 이동한다. 빈칸이 채워져 있다
- **영향 범위**: 나의 공간 화면, 두 문서 페이지

---

## Context

```
관련 파일:
- src/app/space/page.tsx      로그아웃 버튼 아래(링크 위치 후보)
- src/app/privacy/page.tsx    [시행일] · [전화번호] · 개정 이력
- src/app/terms/page.tsx      [시행일] · 부칙
```

### 왜 나의 공간인가

개인정보 처리방침 작성지침(2025.4)은 모바일 앱의 공개 위치로 설정 메뉴 · 회원가입 영역을 허용한다. 무드핏은 설정 화면이 없어 나의 공간이 가장 가깝다. 회원가입 화면 링크는 가입 동의 티켓(후속)에서 붙인다.

---

## Scope

### 포함

1. `src/app/space/page.tsx` — 하단 "이용약관 · 개인정보 처리방침" 링크(로그인 여부와 무관하게 표시)
2. 두 문서 `[시행일]` 채우기 — 배포일
3. 처리방침 보호책임자 `[전화번호]` 채우거나 항목 삭제

### 제외

- 회원가입 동의 체크 · 동의 기록 → 가입 동의 티켓(후속)
