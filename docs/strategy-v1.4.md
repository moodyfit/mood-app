# 전략 v1.4 반영 노트 (무드핏 / MOODFIT)

v1.1 → v1.4 주요 변경점과 앱 구현 매핑. (원본 전략 문서는 대화상 첨부로만 존재)

## 제품명

**무드 → 무드핏 (MOODFIT).** 브랜드·메타데이터 전면 반영.

## 원칙 7 (신설) — 복구 프레이밍

자체를 공격하지 않고 자체의 이름을 붙인다. 공포("무시당하지 마라") ❌ → 복구("이름을 몰랐을 뿐") ⭕.
신조어 **'옷맹'(옷+문맹)**. 추구미 카드의 진짜 문장 = "너는 취향이 없는 게 아니라 이름을 몰랐던 거다."

- 구현: 홈 히어로 "취향이 없는 게 아니에요 / 이름을 몰랐을 뿐이에요", 추구미 카드 하단 복구 문장.

## 감정 설계 (2.5장) — 한국 소비 감정

- **포용성 수치:** "이 무드를 가진 사람, 전체의 X.X%" → 동경(특별함) 아닌 소속감(같은 X%의 존재).
  - 구현: `taste.ts` `rarityFor()` (MVP는 조합 문자열 기반 결정적 의사값, 실서비스는 실제 분포로 대체). 추구미 카드에 표기.
- **부극성 지표:** time-to-추구미카드 (첫 세션 내 '뭘 골라야 할지 안다' 도달) → 검증 지표.

## 시그니처 모먼트 3종 (4.6장) — 체감 차별화 본체

| 모먼트 | 구현 |
|---|---|
| **1. 아무말 검색 → "알아먹는다"** | 홈 플레이스홀더 일상어 로테이션(`SearchScreen`), **실패 없는 검색**: `resolveMoods()`가 미매핑·빈 입력도 폴백 그리드로 응답 (빈 화면이 이 모먼트를 죽이는 유일한 점) |
| **2. 무드 완성가 → "이 살 수 있다"** | 무드 상세 히어로에 "이 룩 완성 · N만" 라벨 (`lookTotal` = 연결 상품 최저가 합산). ※ 그리드 카드는 사용자 지시대로 사진만 유지 → 라벨은 상세에만 |
| **3. [모두의 결과 ↔ 너의 결과] 토글** | `ResultsGrid` 상단 스위치. 추구미 카드 발급 후 노출, `personalizeOrder()`로 취향순 재정렬 → 취향 학습을 유저가 직접 조작 |

## 겹3 체감 장치 (3장) — 기능으로 번역

- **추천 이유 공개:** 상품 위 배너 "이게 뜬 이유 · 네가 저장한 무드와 같은 결" + 근거 무드 썸네일 (`ProductSection`). 충동구매 아닌 "내 취향 소비" 프레이밍.
- **판매처 횡단 가격:** 각 상품 2~3곳 판매처 가격 병기 (`ProductRow`, `types.ProductSource`). 최저가 표시 + 전체 비교. PCPartPicker식 신뢰 본체.

## 2차 요구 재정의 (v1.3)
