# 태깅 규칙 개정 로그 (사람 검수에서 확정 — 이후 배치에 강제 적용)

## 배치 #1 검수 (2026-07-22)

1. **상황 사전 엄수 (지시서 3.3 재확인)**: 사전 9개 = 소개팅/데이트/출근/면접/결혼식하객/주말카페/**동네**/여행/모임술자리. 그 밖(예: '놀거리') 절대 추가 금지. 애매하면 억지로 채우지 말고 빈 배열/최소.

2. **caption_item = 명사구로 종결**: "~입은 사람/~든 사람/~찬 사람" 접미 금지. 예) "오버핏 코치자켓에 세미와이드 슬랙스". 앱 UI에 그대로 실림.

3. **classic 2차축 남용 금지 (핵심)**: 슬랙스·부츠·셋업이 보인다고 반사적으로 classic을 얹지 말 것. **classic은 정장기가 "룩의 정체성"에 기여할 때만.**
   - ❌ clean의 차콜 슬랙스 = 클린 미니멀의 재료 (classic 아님) → 단일 지배.
   - ⭕ cityboy의 셋업 재킷 / amekaji의 브라운 부츠·벨트 = 정장기가 실제 기여 → classic 0.2~0.3 유지 가능.
   - 다음 배치 패턴 학습 체크포인트: soft 축에 classic이 스미지 않는지.

4. **단일축 벡터 허용**: 2차축이 억지스러우면 단일축(예: street 1.0)이 정답. 균등 분산(0.4/0.3/0.3) 금지 원칙의 올바른 적용.

5. **토르소 크롭 규칙 (신설)**: 전신·머리 포함이 **기본**. 얼굴 잘린 토르소 크롭은 패션 에디토리얼 문법이라 무드 전달엔 유효 → **그리드의 20% 이하 보조컷으로만** 채택. **추구미 카드·간판 룩 대표컷은 전신샷만** (동경 원칙: 얼굴·분위기가 연료).
