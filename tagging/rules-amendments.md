# 태깅 규칙 개정 로그 (사람 검수에서 확정 — 이후 배치에 강제 적용)

## 배치 #1 검수 (2026-07-22)

1. **상황 사전 엄수 (지시서 3.3 재확인)**: 사전 9개 = 소개팅/데이트/출근/면접/결혼식하객/주말카페/**동네**/여행/모임술자리. 그 밖(예: '놀거리') 절대 추가 금지. 애매하면 억지로 채우지 말고 빈 배열/최소.

2. **caption_item = 명사구로 종결**: "~입은 사람/~든 사람/~찬 사람" 접미 금지. 예) "오버핏 코치자켓에 세미와이드 슬랙스". 앱 UI에 그대로 실림.

3. **classic 2차축 남용 금지 (핵심)**: 슬랙스·부츠·셋업이 보인다고 반사적으로 classic을 얹지 말 것. **classic은 정장기가 "룩의 정체성"에 기여할 때만.**
   - ❌ clean의 차콜 슬랙스 = 클린 미니멀의 재료 (classic 아님) → 단일 지배.
   - ⭕ cityboy의 셋업 재킷 / amekaji의 브라운 부츠·벨트 = 정장기가 실제 기여 → classic 0.2~0.3 유지 가능.
   - 다음 배치 패턴 학습 체크포인트: soft 축에 classic이 스미지 않는지.

4. **단일축 벡터 허용**: 2차축이 억지스러우면 단일축(예: street 1.0)이 정답. 균등 분산(0.4/0.3/0.3) 금지 원칙의 올바른 적용.

5. **토르소 크롭 규칙 (신설)**: 전신·머리 포함이 **기본**. 얼굴 잘린 토르소 크롭은 패션 에디토리얼 문법이라 무드 전달엔 유효 → **그리드의 20% 이하 보조컷으로만** 채택. **추구미 카드·간판 룩 대표컷은 전신샷만** (동경 원칙: 얼굴·분위기가 연료).

## 배치 #1 (신규 dev 세대) 검수 (2026-07-23)

6. **상황 = 상위 노출 약속**: "그 검색어 친 사람에게 이 사진이 답으로 상위 노출돼도 되는가"로 판정. 반팔 원톤은 '데이트'의 답으로 약함 → '데이트'는 레이어드·포인트 룩에만 아껴 쓴다.
7. **확신 없는 상황은 비운다**: 0~3개 범위, 2개 꽉 채우는 경향 금지. 억지 충전 < 빈 배열.
8. **flagship 근거 필수**: 표시 시 "슬롯별 기본템(유니클로급)으로 재현 가능한가" 1줄. 사진 예쁜 순 아님. 전신·얼굴 대표컷만.
9. **caption_how = 착용 디테일만** (넣기/걷기/기장/소매 등). 스타일 조언·평가 금지.
10. **벡터 규율**: 단일축 몰아주기 기본, 부축은 기여 근거 명시할 때만(예: clean-002 릴렉스 카페 → cityboy 0.2).
11. **5단계 seed.sql**: 기존 힉스필드 태깅 8행 DELETE 후 신규분 대체 포함.

## 배치 #2 검수 (2026-07-23)

12. **색·소재 교차검증 (무관용)**: caption_why의 색/소재 서술은 caption_item 아이템 목록과 반드시 교차검증 후 제출. item에 유채색(네이비 등)이 있으면 '무채색' 표현 금지. (caption_why 거짓 = 롱프레스 전체 신뢰 붕괴) — 예: clean-007 네이비→차콜 정정.
13. **시즌 커버리지 보고**: 매 배치 자기점검에 축별 시즌 배분 1줄(예 "clean: SU4 / FW2 / 간절기1 — 010~015가 spring·fall 보충"). 축당 시즌 공백이 잔여 계획에 반영됐는지 확인.

## 배치 #4 검수 (2026-07-23)
14. **근접 중복 체크(상시)**: 동일 축 내 아이템 조합(상의+티+하의)이 기존 승인분과 일치하면 표에 표시. 시즌 차이는 중복 해소 사유 아님(배경·핏·아우터·색 등 실질 변별 필요). 사실상 동일 컷이면 변주 재생성 후보(로고 재생성 배치 합류). 예: cityboy-006 vs 010 → 반팔 워크셔츠+올리브 와이드 vs 긴팔 코치+카멜 치노로 변별(기록).
15. **자기점검 인용 정확도**: 색 교차검증 등 자기점검에 인용하는 파일·색은 표와 일치시킬 것(예: 배치#4 '014 브라운'은 오기, 실제 014=카키·올리브).
16. **90장 완료 시 전 축 통합 시즌 매트릭스 1회 제출**(겨울 그리드 총량 최종 확인). cityboy heavy-winter는 amekaji·classic·soft에 위임 승인됨.

## 배치 #5 검수 (2026-07-23)
17. **주축/부축 중복 판정**: pose·배경은 부축 변별, 아이템 조합(상의+티/이너+하의)은 주축. 주축이 겹치면 부축으로 구제하지 않는다 → 변주 재생성. (street-011=009와 주축 동일 → 011 재생성)

## 배치 #7 검수 (2026-07-23)
20. **seasons=실물 원칙**: seasons는 생성 계획이 아니라 사진에 찍힌 옷을 따른다(예 classic-006 계획 summer→실물 카멜코트=FW).
21. **골격 변경 전용 재생성**: 근접중복이 축 전체의 단일 문법 색 순열일 땐 색 변주 금지, 골격 변경만 허용(classic-008·012 → 셔츠+타이/니트베스트/발마칸·트렌치/카디건+셔츠 중 택, 서로 다르게).
22. **여름 총량 판정**: classic·street·amekaji SU0 확정 → 여름 그리드는 clean·cityboy만(약 11장). 통합 매트릭스에서 여름 상황어(소개팅·데이트) 대비 충분성 판정.
23. **soft 경계(#8)**: soft 니트/가디건이 기존 clean(크림 니트)·classic(카멜 터틀넥) 승인분과 "다른 축 같은 옷" 되지 않게 **축 횡단 근접중복 체크**. 변별 = 실루엣(라운드·포근) + 골격(가디건·집업·플리스) + 웜톤. 크림니트+슬랙스 미니멀은 clean 영역 → soft로 넘기지 말 것.
