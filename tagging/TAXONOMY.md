# 무드핏 스타일 택소노미 & 스코어링 루브릭 v2

담당: 케빈 (전시 사진 고도화 + 태깅/점수) · 계약 상대: 에린(개인화 랭킹)
목적: 각 사진에 **정확한 다축 스타일 점수**를 일관되게 매겨, 개인화(`rank.ts`의 mood_vector 내적)와 전시 다양성이 제대로 작동하게 한다.

---

## 0. 왜 v2인가 (현재 문제)
- 지금 `mood_vector`는 **90장 중 89장이 one-hot**(`{clean:1}`) — 생성 폴더 라벨일 뿐, 실제 스타일 점수가 아님.
- 개인화 랭킹은 이 벡터의 내적으로 도는데, one-hot이면 사실상 **6버킷 분류**. → 다축 분포로 정확화하면 개인화 해상도가 즉시 상승.

## 1. 축 세트 (확정: 6축 유지)
`clean · cityboy · street · amekaji · classic · soft`
- 이 6축은 앱 전체(생성/`resolveMoods`/`rank.ts`/DB)에 박혀 있어 **세트 변경 비용이 큼** → 이번 이터레이션은 **세트 유지 + one-hot→다축 분포**에 집중.
- 댄디·미니멀·워크웨어 등 세부 스타일은 **축이 아니라 "어휘"** 로 취급해 6축에 매핑(§4). 세부 서브축은 다음 이터레이션 후보(§6).

## 2. 스코어링 규약 (mood_vector 스키마 — 에린과의 계약)
```json
{ "street": 0.6, "amekaji": 0.4 }   // 6축 중 유의미한 것만, 합 = 1
```
- **범위**: 각 축 0~1, **합 = 1로 정규화**(분포). 스케일 일관성 → 내적 랭킹이 공정.
- **주축**: 가장 높은 축 ≥ 0.5 (한 장은 하나의 지배 스타일을 가진다).
- **부축**: 나머지를 배분, **< 0.1은 0으로 버림**(노이즈 컷). 유의미 축은 **최대 2~3개**(과분산 금지).
- **confidence** (0~1, 선택): 애매하면 낮게 → 사람 검수 우선순위 큐로.
- **caption 3행 유지**: `item`(무엇) / `why`(왜 이 무드) / `how`(입는 법). 색·소재 서술은 사진과 **사실 일치(무관용)**.
- **seasons**: 실물 기준(반팔=summer 등).

## 3. 6축 루브릭
각 축 = ①한 줄 본질 ②시각 신호(핏/아이템/색/디테일) ③혼동축 구분 ④앵커.

### clean — 클린 미니멀
- **본질**: 군더더기 없이 정제·정돈. "색을 안 늘려서" 대충 입어도 깔끔.
- **신호**: 매끈한 소재 · 색 2개 이하 · 로고/패턴 최소 · 과하지 않은 정핏.
- **대표템**: 화이트 티/셔츠, 슬랙스, 미니멀 로퍼·스니커.
- **색**: 화이트·아이보리·그레이·블랙 (무채+뉴트럴).
- **혼동**: `soft`(클린=매끈·절제 / soft=니트 질감·포근), `classic`(클린=캐주얼 정돈 / classic=테일러링).
- **앵커**: `clean-001`, `clean-012`.

### cityboy — 시티보이
- **본질**: 재핑한 레이어드, 캐주얼과 단정 사이(일본 시티보이). 소품으로 층을 만든다.
- **신호**: 셔츠·셋업 걸치기 · 토트백 · 레이어 · 밝은 뉴트럴.
- **대표템**: 오픈셔츠·코치자켓·셋업, 화이트 티, 와이드 팬츠, 토트백.
- **색**: 베이지·카키·네이비·화이트.
- **혼동**: `clean`(시티보이=소품·레이어 많음), `amekaji`(시티보이=더 도시적·정돈).
- **앵커**: `cityboy-001`, `cityboy-008`.

### street — 스트릿
- **본질**: 오버핏·볼륨, 도시적 날것. 위아래 다 크게, 힘 뺀 듯.
- **신호**: 오버사이즈 실루엣 · 후디/카고 · 캡 · 워시드.
- **대표템**: 오버핏 후디·헤비코튼 티, 카고·와이드 데님, 볼캡, 스니커.
- **색**: 블랙·올리브·워시드 톤.
- **혼동**: `amekaji`(스트릿=현대 오버핏 / amekaji=빈티지 워크웨어).
- **앵커**: `street-001`, `street-011`.

### amekaji — 아메카지
- **본질**: 워크웨어·데님·밀리터리, 빈티지 손맛. 낡은 느낌이 멋.
- **신호**: 청청/데님 레이어 · 워크자켓·트러커 · 흙색 톤 · 워크부츠.
- **대표템**: 데님 트러커·셰르파, 워크팬츠, 레더 워크부츠.
- **색**: 인디고·에크루·올리브·브라운.
- **혼동**: `street`(아메카지=빈티지·워크 / 스트릿=오버핏 현대), `cityboy`.
- **앵커**: `amekaji-002`, `amekaji-013`.

### classic — 클래식
- **본질**: 셋업·코트·구두, 정돈된 테일러링. 각 잡혔는데 안 답답.
- **신호**: 테일러드 재킷/코트 · 터틀넥 · 울 슬랙스 · 구두/로퍼 · 세로 라인.
- **대표템**: 오버코트·블레이저, 니트 폴로, 울 슬랙스, 페니 로퍼.
- **색**: 차콜·네이비·그레이·브라운.
- **혼동**: `clean`(클래식=테일러링·격식 / 클린=캐주얼 정돈).
- **어휘 흡수**: **댄디**, 포멀, 프레피, 테일러드 → 여기.
- **앵커**: `classic-001`, `classic-014`.

### soft — 소프트 캐주얼
- **본질**: 니트·가디건, 부드러운 톤. 포근하게 정리.
- **신호**: 니트/가디건/플리스 질감 · 크림·파스텔톤 · 편안한 실루엣.
- **대표템**: 가디건·니트·플리스 블루종, 치노.
- **색**: 크림·오트밀·베이지·연톤.
- **혼동**: `clean`(소프트=질감·포근 / 클린=매끈·절제).
- **앵커**: `soft-002`, `soft-010`.

## 4. 스타일 어휘 → 축 매핑 (일관성 사전)
| 흔한 말 | 축 |
|---|---|
| 미니멀 · 놈코어 · 심플 · 깔끔 | clean |
| 댄디 · 포멀 · 프레피 · 테일러드 · 정장룩 | classic |
| 워크웨어 · 헤리티지 · 빈티지 · 밀리터리 · 청청 | amekaji |
| 오버핏 · 힙합 · Y2K · 카고룩 | street |
| 시티보이 · 아이비 · 재팬캐주얼 | cityboy |
| 코지 · 니트룩 · 뉴트럴 니트 | soft |

혼합은 **분포로**: 예) "댄디 스트릿" → `{classic:0.6, street:0.4}`, "미니멀 워크" → `{clean:0.6, amekaji:0.4}`.

## 5. 스코어링 절차 (D2~3에서 적용)
1. 사진 1장 → 6축 각 0~1 러프 채점(루브릭 신호 대조).
2. < 0.1 버림 → 남은 축 합=1로 정규화 → 주축 ≥0.5 확인.
3. 애매하면 confidence 낮게 표시.
4. `caption`(item/why/how) 사실 일치 확인.
5. **비전 모델 자동 채점 → 사람 검수**(케빈)로 확정.

## 6. 검수(정확도) 프로토콜
- **자동 vs 사람 상관**: 파일럿 10장에서 주축 일치율 ≥ 80% 목표. 미달 시 루브릭 신호 보정.
- **인터레이터**(가능하면): 2인 독립 채점 → 주축 일치율 확인.
- **레드플래그 재검수**: confidence < 0.5 / 부축이 0.4 넘는데 근거 모호 / caption 색·소재 불일치.

## 6.5 신규 사진 추가 시 태깅/채점 절차 (재현 파이프라인)
루브릭은 **`tagging/rubric.ts` 단일 소스**(축 정의·어휘·mood_vector 계약). 채점기·검증기가 여기서만 import → 회차/사람 간 드리프트 없음. **이 규약을 바꾸려면 rubric.ts 한 곳만** 고친다.

새 사진을 `images/post/{axis}-NNN.jpg`(또는 임의 이름)로 넣은 뒤:
```
# 0) (최초 1회) .env.local 에 ANTHROPIC_API_KEY=... 추가
npx tsx scripts/score-photos.ts images/post/clean-016.jpg   # 이미지→tagging/*.json 자동 채점(비전)
#   또는 폴더 통째:  npx tsx scripts/score-photos.ts images/post   (태깅 없는 것만)  · --force 로 재채점
npx tsx scripts/validate-tags.ts                            # 계약 게이트(합=1·주축≥0.5·<0.1컷·≤3축·어휘). 위반 시 exit 1
npx tsx scripts/upload.ts                                   # Storage 업로드(있으면 skip/overwrite)
npx tsx scripts/apply-photos.ts                             # DB upsert(기존 UPDATE, 신규 INSERT). id·FK 보존
```
- **정확성 보장 장치**: 채점기는 rubric.ts의 6축 루브릭+계약으로 채점 → `normalizeMoodVector`로 <0.1컷·정규화 → `validateTag` 게이트가 계약 위반을 **차단**. `confidence<0.85`는 사람 검수 큐로 출력.
- 모델 override: `ANTHROPIC_MODEL`(기본 claude-sonnet-5). 비용 대략 장당 $0.01 미만.
- 축 자체를 늘리려면 §7 + rubric.ts의 `AXES`/`AXIS_RUBRIC` 갱신(에린과 마이그레이션 합의).

## 7. 축 확장 정책 (다음 이터레이션)
- 6축으로 표현이 부족한 스타일(예: 스포티, 고프코어, 미니멀-테일러드)이 데이터로 반복 확인되면 **서브축** 도입 검토.
- 확장 시 에린과 마이그레이션 합의(기존 벡터 재정규화 + `rank.ts`·`resolveMoods` 갱신).
