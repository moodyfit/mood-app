# 무드핏 카드뉴스 v3 (인스타용)

기준: `moodfit-cardnews-production-guide-v3.md`. v3가 v2 §3(해설 카드 주력)을 **4유형 × 포맷 로테이션**으로 대체하고, v2 §4(언어 허법)는 그대로 우선. 콘텐츠 판단의 단일 기준은 가이드라인이며, 이 폴더는 그 산출 파이프라인이다.

## 무엇을 만들었나 — 초기 4주 런칭 시퀀스 (§5)

**12게시물 · 총 43장.** 팔로워 대기 우선 배합 **E5 · S5 · I1 · H1**.

| 주 | 테마 | 편성 (요일) |
|---|---|---|
| **W1** | 정체성 심기 | E(월) · S(수) · E(금) |
| **W2** | 감각 증명 | S(월) · I(수) · S(금) |
| **W3** | 확산 시도 | E(월) · S(수) · E(금) |
| **W4** | 첫 제품 테스트 | E(월) · S(수) · **H(금)** |

- 같은 유형 연속 배치 금지, H는 금요일 고정, 첫 게시는 E (§1).

## 4유형 (§1~§2)

| 유형 | 역할 | 이 시퀀스의 구현 |
|---|---|---|
| **E** 공감 | 관계 형성·공유 — "나잖아" | 거울 앞/무난/니트/검정옷장/장바구니. 복구 착지로 마감 |
| **S** 감각 | 플레이스로 자격 증명 — "얘 뭐 좀 아네" | flagship 룩 사진 주인공, `why`를 **구어 번역**(원문 미노출) |
| **I** 정보 | 반전 해석 한 줄 — "아 그거였어?" | 시티보이 셔츠. F2훅→F3주석→F1정답→F2착지, **정보 문장 정확히 1개** |
| **H** 훅/홍보 | 시간 포화·오프성 전환 | 여름 D-3, flagship 3룩 + 완성가 22.6만 + 앱 검색(H만 앱 언급 허용) |

## 7 포맷 로테이션 (§3.2)

F1 텍스트 · F2 풀블리드 사진 · F3 주석(시그림) · F4 채팅 재현 · F6 그리드 뭉치 · F7 블랙 반전.
(F5 비포/애프터 좌우분할은 **대비 촬영본이 없어 이번 시퀀스에서 제외** — §9 항목으로 남김.)

## 가이드라인 준수 (자동 검수 — `plan.md`에 전편 표로 출력)

- **금지어 0** (정답·트렌드·베스트·인기·핫·특가·저렴이·가성비·옷맹·요즘) — 전 12편 스캔 통과
- **정보 문장** = I편 1개, E·S·H편 0개 (§0-5)
- **공유어**(꾸안못·팔로무드러) **주 합산 ≥2** — W1~W4 전부 충족
- **caption 원문 미노출** — 태깅 `why`는 목격·구어체로 번역해서만 노출 (§2)
- **복구 착지** — E·I 마지막 장은 "네 탓이 아니라 [원인]" 구조
- **앱 언급** H에서만 / **경쟁·실존 브랜드·타 앱 0**
- **완성가** = 앱 `MoodHero`와 동일 산식(미드 티어 최저가 합산 → 22.6만)

## 디자인 시스템 (§3)

- 고정 앵커: `MOODFIT` 좌상단 · 페이지 도트 하단중앙 · 마지막 장 저장. 사진 상단엔 로고 스크림.
- 유형 액센트 1색: **E** 웜 테라코타 · **S** 사진 원색(무액센트) · **I** 머스터드 · **H** 블랙 반전.
- 규격 1080×1350(4:5). 토큰은 앱과 동기화(paper #FAFAF8 / ink #1A1A1A).

## 사용법

```bash
node build-v3.mjs   # 콘텐츠 플랜 → 낱장 HTML + index.html + plan.md 생성
bash export.sh      # 낱장 → out/<게시ID>/<장>.png (Chrome headless, H는 블랙 배경)
open index.html     # 주차별 리뷰 갤러리 (유형 배지·해시태그·요일)
open plan.md        # 게시계획 + 자가검수 표
```

인스타 업로드: `out/<게시ID>/`의 장을 1→N 순서로 캐러셀 게시. 요일·해시태그는 `plan.md` 참고.

## 파일

```
cardnews/
  build-v3.mjs     콘텐츠 플랜(12편) + 렌더러(F1~F7) + 자가검수. 단일 소스.
  export.sh        Chrome headless PNG 내보내기 (dark 카드 배경 분기)
  index.html       주차별 리뷰 갤러리 (build 산출)
  plan.md          게시계획 + 자가검수 체크표 (build 산출)
  manifest.json    낱장↔PNG 매핑 (build 산출)
  render/*.html    1080×1350 낱장 43장
  out/<게시ID>/*.png  최종 인스타 이미지
```

## 편성/문구 바꾸려면

`build-v3.mjs`의 `POSTS` 배열만 수정 → `node build-v3.mjs && bash export.sh`.
- 카피는 각 카드의 `lead`/`caption`/`common`/`bubbles` 등. **금지어·복구 착지·공유어 규칙 유지** — 재빌드 시 `plan.md`가 자동 재검수.
- S/I의 룩 이미지·`why` 소재는 flagship 태깅 승인본에서만. caption 원문 그대로 박지 말 것(구어 번역 필수).
